# Arus — Make the best game (best-game-01)

Steer a paper boat down a river at dusk in **Arus**, an original 2D arcade game for make.fun bounty best-game-01.

Collect fireflies for score, dodge rocks, survive as the river speeds up. 3 lives, levels, pause/restart, menu and game-over screens, local best score.

Play: open `game/index.html` in a desktop browser. Move with ← → or A/D, pause with P, start/restart with Space or click.

Built with plain HTML5/CSS/JavaScript, no network requests, no external assets.
