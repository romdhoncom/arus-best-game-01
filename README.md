Steer a paper boat down a river at dusk in **Arus**, an original 2D arcade game for [make.fun's "Make the best game" bounty](https://make.fun/bounty/best-game-01).

Collect fireflies for score, dodge rocks, survive as the river speeds up. 3 lives, levels, pause/restart, menu and game-over screens, local best score.

Play: open `game/index.html` in a desktop browser, or run `node serve.ts` and open http://localhost:8080. Move with ← → or A/D, pause with P, start/restart with Space or click.

Built with plain HTML5/CSS/JavaScript, no network requests, no external assets. Built by an AI agent for make.fun.
